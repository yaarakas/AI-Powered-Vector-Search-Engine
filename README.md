# AI-Powered Vector Search Engine

This project implements a semantic vector search system in C# using AI-generated embeddings and similarity search techniques.

## Features
- Vector embedding generation using LLM APIs
- Semantic search over stored document vectors
- AI-generated explanations and responses
- Performance measurement and optimization
- File-based vector retrieval

## Technologies
- C#
- .NET
- REST APIs
- Vector Search
- JSON
- File Processing

## How It Works
1. User submits a query
2. The system generates vector embeddings
3. Vector similarity search retrieves relevant documents
4. AI generates a contextual explanation for the result
